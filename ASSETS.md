# Ícones e recursos visuais

A pasta [`icons`](./icons/) contém 58 PNGs fornecidos junto com as cenas. Os arquivos foram regravados sem metadados de conta, caminhos locais ou identificadores internos do Canva; o conteúdo visual foi preservado.

## Organização

- `icons/`: ícones de edição, transporte e atalhos gerais;
- `icons/Ícones do Canva Personalizados/`: variações criadas para a cena do Canva;
- `icons/Ícones do Resolve Personalizados/`: variações criadas para DaVinci Resolve.

As imagens variam entre 126×126, 500×500, 1080×1080 e 1254×1254. O Stream Dock redimensiona a imagem para a tela do botão. Em outras controladoras, exporte uma cópia no tamanho recomendado pelo fabricante.
